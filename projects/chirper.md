{% projectSection "Trim bird audio automatically" %}
{% projectAutoplayVideo "/media/chirper/trim-bird.mp4", "Chirper trim bird audio automatically" %}
Chirper takes long bird recordings and automatically turns them into individual clips, organized by species.
{% endprojectSection %}

{% projectSection "Import audio directly from Merlin" %}
{% projectPhoneStage "/media/chirper/import-bg.jpg", "/media/chirper/import.mp4" %}
Import an audio file or bring in a recording from Merlin.
{% endprojectSection %}

{% projectSection "Adjust each clip" %}
{% projectPhoneStage "/media/chirper/trim-bg.jpg", "/media/chirper/trim.mp4" %}
Listen to each detection, remove the ones you don't want, or adjust the start and end points if the trim is a little off.
{% endprojectSection %}

{% projectSection "Filter by confidence" %}
{% projectPhoneStage "/media/chirper/filter-bg.jpg", "/media/chirper/filter.mp4" %}
Dial the confidence threshold up or down to hide weak detections and keep the matches you trust.
{% endprojectSection %}

{% projectSection "Export by species" %}
{% projectPhoneStage "/media/chirper/export-bg.jpg", "/media/chirper/export.mp4", "sound" %}
Export individual clips grouped by species, ready to save, share, or use somewhere else.
{% endprojectSection %}

{% projectSection "Share to Instagram" %}
{% projectPhoneStage "/media/chirper/instagram-bg.jpg", "/media/chirper/instagram.mp4", "sound" %}
Turn your birding session into an Instagram Story with the species you found and a background of your choice.
{% endprojectSection %}
